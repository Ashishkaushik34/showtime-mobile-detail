# Showtime Mobile Detail & Pressure Washing 🚗✨

> **Houston's 5.0-Star Rated Mobile Auto Detailing & Residential Pressure Washing**  
> We bring showroom shine and exterior restoration directly to your doorstep across Greater Houston, TX.

---

## 🌟 Highlights & Features

### 🚘 Public Website
- **Hero Showcase:** High-converting hero with 5.0-star badge (155+ Google reviews), instant quote and direct call/text triggers.
- **Auto Detailing Services Grid:** Dynamic services including Full Interior & Exterior Detail, Ceramic Coating, Engine Bay Detailing, and Paint Correction.
- **Residential Pressure Washing Section:** Dedicated exterior restoration showcase for Driveways, Decks, Patios, Siding, and Mildew Removal.
- **Interactive Before & After Comparison:** Custom split-slider cards with drag-to-reveal before/after transformations for interior, paint, engine, wheels, and driveways.
- **Verified Customer Testimonials:** Reviews highlighting 24-hr turnaround, 6+ year stain removal, and showroom finishes across Houston neighborhoods (River Oaks, The Woodlands, Katy).
- **Instant Free Estimate Calculator:** Multi-step quote request system with vehicle size, Houston ZIP code, preferred arrival windows, and instant booking reference generator.
- **Mobile Sticky Quick-Action Bar:** Floating bar on mobile devices for one-tap calling, SMS texting, and online booking.

### 🔐 Admin Panel (`/admin`)
- **Protected Login:** Seeded credentials (`admin@showtime.com` / `showtime2024`).
- **Live Stats Overview:** Total quote requests, new leads today, and active services count.
- **Leads & Quote Requests Manager:** Searchable & filterable table with real-time status updates (`New`, `Contacted`, `Scheduled`, `Completed`).
- **Services Manager:** Add, edit, or toggle services active/inactive with changes reflecting live on the public site.
- **Gallery & Reviews Manager:** Add or delete before/after transformations and verified customer reviews.
- **Zero Backend Required:** Fully powered by local persistent storage (localStorage) — deploy 100% free on Vercel or Netlify.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Ashishkaushik34/showtime-mobile-detail.git
cd showtime-mobile-detail
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
